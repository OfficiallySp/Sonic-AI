# Sonic Clone - Controls & Features

## Keyboard Controls

| Action | Key(s) |
|--------|--------|
| Move Left | Left Arrow |
| Move Right | Right Arrow |
| Jump | Up Arrow, Space |
| Spin Dash (charge) | Down Arrow, C |
| Start Game | Enter, Space (on menu) |

## Spin Dash Tutorial

The spin dash is Sonic's signature move for quick bursts of speed:

1. **Stop** - Stand still on solid ground
2. **Charge** - Hold Down or C key
3. **Release** - Let go to launch forward

The longer you charge, the faster you'll go. Use it to:
- Quickly reach top speed from a standstill
- Cross gaps
- Defeat enemies by rolling into them

## Rolling

When your horizontal speed exceeds a certain threshold, Sonic automatically curls into a ball (rolling state). In this state:
- You can defeat enemies by touching them
- You maintain momentum while crouched
- Friction gradually slows you down

Build speed by running or using the spin dash!

## Scoring

| Action | Points |
|--------|--------|
| Collect ring | 100 |
| Defeat enemy | 1,000 |
| Time bonus | 50 per second remaining |
| Ring bonus (level end) | 100 per ring held |

Complete levels quickly and with many rings for the highest scores!

## Game Flow

1. **Menu** - Press Enter to start
2. **Level 1** - Green Hill Zone (grass theme)
3. **Level 2** - Marble Hill Zone (stone theme)
4. **Game Over** - Lose all 3 lives
5. **Victory** - Complete both levels

## Tips

- **Collect rings before getting hit** - Scattered rings disappear after ~2 seconds
- **Use checkpoints** - Touch the tall posts to save your position
- **Stay invincible** - After being hit, you flash for 2 seconds (can't take damage)
- **Roll through enemies** - Faster than jumping when you have momentum
